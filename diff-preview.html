📌 对比要点：
高度：旧版词级背景只盖住文字内容区（矮一截），新版用 display: inline-block; padding: 0.275em 0 撑满行高 ← 与行级底色齐平
间隔：旧版每个 token 独立 <ins> → 相邻色块之间有 断裂间隙，新版合并相邻同类型 → 连续无间隔
混合行（第 4-5 行）：equal 词（无背景）保持原样，仅左右两侧的 insert/delete 合并。
